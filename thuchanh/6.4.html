Cấu trúc cơ bản của JSON (Kiến thức 6.4)

{ "interface": { "name": "GigabitEthernet1", "description": "Uplink", "enabled": true, "ip_addresses": [ "10.0.0.1", "192.168.1.1" ] } }

Dấu ngoặc nhọn { } đại diện cho một Object (Đối tượng).

Dấu ngoặc vuông [ ] đại diện cho một Array (Mảng / Danh sách).

Dữ liệu được tổ chức theo cặp "Key" : "Value".

Lỗi phổ biến: Quên ngoặc kép ở Key, dư dấu phẩy (,) ở phần tử cuối cùng, hoặc thiếu ngoặc đóng.
