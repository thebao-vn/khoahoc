THE BÁO: [Phần 5.4] Cấu hình và xác minh ACLs

Security Fundamentals

Nhiệm vụ: Cấu hình Router (R1) sử dụng Standard ACL để chặn PC2 (192.168.1.10) truy cập Web Server, nhưng vẫn cho phép PC1 (192.168.1.5) truy cập bình thường. Chú ý thứ tự Rule và luật "Implicit Deny" ở cuối mỗi ACL!

PC1 (Admin) 192.168.1.5
PC2 (Guest) 192.168.1.10
g0/0 g0/1
R1 ACL 10: IN
Web Server 10.0.0.5

Bảng Điều Khiển Tự Động
